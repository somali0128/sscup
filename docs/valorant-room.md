# 无畏契约轮盘房间

入口：`/valorant`，首页导航已增加「无畏契约轮盘」。推荐手机使用，裁判也可使用电脑总览。

## 已实现

- 创建密码由后端环境变量校验；加入必须输入游戏昵称与六位房间码。
- 13 人总容量，左右队各最多 5 人，可不满员、不等人数开始。
- 房主指定裁判；开局锁定名单、队伍、裁判身份与抽取模式。
- 27 个事件，共用事件池、独立等概率抽取、允许连续重复；轮盘直接显示效果，不附加说明。
- 自由模式可自行随时重抽；统一模式由房主或裁判点击全员重抽。
- 进入下一回合前，**房主必须确认本回合胜负**（左队胜 / 右队胜，弹窗二次确认并预览比分）；确认后记录全员本回合效果与重抽次数，自动进入下一回合并全员重抽，均在同一事务中保存。单独全员重抽不增加回合数。
- 结束本场时房主确认最后一回合结果，或选择「未打完，不计入」。房主可在进行中及结束后（返回大厅前）修正任一回合胜负，修正记录保留在抽取明细中。
- 比分与每回合胜方对所有人公开；对方效果仍保密到结束。
- 回合类操作（个人抽取、全员重抽、确认胜负、结束）按「同一场 + 同一回合」校验，其他玩家的自由重抽不会让房主的确认因版本过期而失败；选队也不再因他人同时加入而报错。
- 玩家和参赛房主只收到本队结果；未参赛房主、裁判可看全部。
- 同设备自动恢复；更换设备通过房主/裁判核实后的恢复码重新绑定身份，旧设备失效。参赛管理员只能恢复本队成员。
- 房主主动移交；连续离线 60 秒后，指定裁判可接管。
- 结束后向该场成员公开历史；「战绩·数据」页给出比分、特别奖（天选之人、连胜引擎、命中注定、百变玩家、虽败犹荣、重抽狂魔）、玩家胜率/重抽/效果数、各效果胜率和回合时间线。可下载回合战绩 CSV、抽取明细 CSV、完整 JSON（含统计结果）；从结束时起保留 30 天。
- 轮盘演出：全屏轮盘，加速—匀速—减速到结果，指针随格子拨动、可选音效与震动，落定后高亮该格并展示自己和队友效果，约 4 秒后自动关闭并回到页面顶部；点按可跳过。每台设备每次抽取只播放一次，刷新不重播；支持「减少动态效果」系统设置。
- 手机布局：对局页顺序为「我的效果 → 队友效果 → 回合结算（房主）→ 对方 → 回合记录 → 设置 → 成员」，320×568 起不滑动即可同时看到自己与全部队友效果。
- 结束后返回大厅复用房间；历史按场次独立保存，不随房间复用续期。

## 前后端连接

前端沿用 `VITE_SOMA_API_URL`。未配置时，生产使用现有 Soma API 地址，开发使用 `/api` 代理。

先部署后端新增的 `/api/valorant`，再发布前端。**本次更新同样必须先部署后端**：新前端会发送 `winner`、`round`、`gameId` 字段并调用 `view=summary`，旧后端的严格校验会拒绝。旧房间文档缺少回合记录字段时会自动补齐，无需迁移；更新前已结束的场次没有胜负数据，数据页会提示暂无分析。设置后端环境变量 `VALORANT_CREATE_PASSWORD` 为约定密码；不要把值写入 Git、README 或任何 `VITE_` 变量。现有 MongoDB 与允许来源设置继续使用。

`backend/soma-api/` 保存本次后端新增文件的镜像，路径相对于独立后端仓库。它不是前端运行时依赖，也不会被 Vite 打包。后端原有文件保留不动。该目录的 `VALORANT.md` 包含 API、索引、身份与事务说明。

数据库必须支持 MongoDB 事务。首次访问创建房间、场次、操作日志、请求回执、限流、在线状态六类集合和索引。服务端严格判断过期时间，TTL 后台负责物理删除。

## 修改事件

在后端仓库编辑 `lib/valorant-events.ts`（本地镜像：`backend/soma-api/lib/valorant-events.ts`），增加版本号并部署后端。新对局使用新配置；进行中的对局和已保存历史不被改写。前端从服务器读取完整事件池，不需要维护第二份规则。

## 本地验证

- 前端：`npm run build`，新增文件通过 ESLint。
- 后端：`npm run check`，新增 15 个房间规则测试，加上原有 4 个测试通过。
- 真实 MongoDB 副本集与实际 API handler：已验证鉴权、双方隔离、重复请求幂等、过期版本冲突、全员一致抽取、身份恢复、公开历史和 30 天期限。
- 三个独立浏览器会话：手机创建/加入/选队，房主参赛，裁判抽取/结束，刷新恢复及 CSV 下载均通过。
- 320、360、390、1280 像素布局无横向溢出，浏览器无页面异常。

前端开发代理可临时设置 `SOMA_API_PROXY_TARGET=http://127.0.0.1:4318`，用于连接隔离测试 API；该变量只在 Vite 开发服务器读取，不进入浏览器包。

现有全仓库 `npm run lint` 仍有三个此前已有的问题：Footer 的未使用 catch 变量，以及雀魂、街霸报名页的同步 Effect 状态更新。本次新增代码检查通过。

## 上线后验收

本地验证未使用生产数据库。发布后仍需用两部手机、一名裁判在真实网络中做一次烟雾测试，确认 API 来源配置、创建密码、MongoDB 索引/事务权限与国内网络延迟。不能将本地测试等同于已上线。
